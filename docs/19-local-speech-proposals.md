# Локальные предложения замеров М2

Парсер работает над текстом на устройстве без сети и сторонних моделей. Браузерное распознавание Web Speech API сохраняет свои прежние ограничения; автономность парсера не означает автономность самого STT.

## Контракт

`extractMeasurementProposals(transcript, elementType)` возвращает строгие FieldProposal с параметром, исходным числом, единицей, исходной фразой, стабильным ID по позиции/значению и уверенностью. `exact` означает явную единицу в тексте; `inferred` означает выбор единицы по параметру, а не статистическую уверенность модели.

Русские числительные 0–999, составные числа, цифры с запятой/точкой, целые с десятыми/сотыми, «полтора», «полторы», «с половиной» преобразуются детерминированно. Исходный фрагмент сохраняется без изменения регистра и пунктуации. Единицы: мм, см, м, проценты, градусы.

Контекст ограничивает предложения: дверь (doorWidth, thresholdHeight), пандус (rampSlope, rampWidth), площадка (landingDepth). Поручни и кнопка не получают предложений этого набора. Неоднозначные отрицания, интервалы, приблизительные значения и фразы о желаемых изменениях пропускаются. Несколько явно названных фактов дают несколько чипов для самостоятельного выбора. Профиль не является общим пониманием русского языка; непривычные обороты можно исправить вручную в черновике.

## Принятие

Предложения отображаются в остановленном черновике комментария, включая черновик, восстановленный с устройства. Живой interim и черновик рекомендации не используются для заполнения фактических замеров.

Клик принятия сначала завершает сохранение и сверяет исходные auditId, zoneId, elementId, актуальный текст и доступность редактора. Непустое поле требует отдельного подтверждения замены. После проверки числа setMeasurementInput и recordMeasurement поступают синхронно в одну очередь и сохраняются одним flush, одной ревизией и атомарной транзакцией действующего audit-store. Norm-engine вызывается для приведённого значения, а результат отображается в панели и под полем карточки. Готовность карточки остаётся ручной.

Нажатие отклонения не пишет в базу. Принятый или отклонённый чип скрывается в текущем сеансе; состояние скрытия не добавляется в схему IndexedDB. Сам голосовой черновик сохраняется и может быть отдельно добавлен к комментарию. Ошибка сохранения сохраняет команды в существующей очереди; конфликт ревизий разрешается штатным редактором. Закрытие/смена черновика до завершения подготовительного flush отменяет принятие устаревшего предложения.

## Проверки

`speech-parser.test.ts`: числа, дроби, обязательные примеры задачи, единицы, контекст, исходная фраза, стабильность, отсутствие ложных предложений при отрицаниях, рекомендациях, диапазонах и некорректных дробях.

`voice-browser.mjs`: появление предложений без записи, атомарное принятие с приростом одной ревизии, отклонение без записи, подтверждение/отмена замены, изоляция двух дверей, norm-engine и принятие без сети с последующим восстановлением.
