# Архив первоначальной концепции

Документы в этой папке описывают концепцию до смены фокуса 22 сентября 2026 года. Упоминания MVP, автоматической обработки, PostGIS и расчёта маршрутов относятся к прежнему объёму и не описывают работающий пилот.

Актуальные требования — [03-requirements.md](../03-requirements.md), назначение продукта — [01-problem-statement.md](../01-problem-statement.md). Архив сохранён для истории решений и возможного возвращения к исследованию графа; развитие этих функций сейчас не запланировано.

ADR о свежести находится в [../adr/ADR-001-freshness.md](../adr/ADR-001-freshness.md). В нынешнем пилоте нет Accessibility Impact; применим только общий принцип: отсутствие новых сведений не доказывает устранение.
