# Публикация приложения

Рабочий интерфейс содержит только обследования объектов. Кнопки маршрутов удалены; ссылки `#/routes` перенаправляются в список обследований. Старые записи маршрутов сохраняются в IndexedDB, но прежний интерфейс не включается в production-сборку.

Плашка живого тестирования скрыта. Статусы реального офлайн-режима, ошибки и предложение безопасного обновления приложения сохранены.

Исходники хранятся в ветке main. GitHub Pages публикует только содержимое production-каталога dist из ветки gh-pages. Локальные QA-артефакты и node_modules не публикуются. Команда сборки: pnpm build. Базовый URL: /UrbanAccess-Accessibility-Audit-Routing/frontend/.

При следующей публикации сначала собрать приложение, проверить его, затем обновить gh-pages содержимым dist. Существующая PWA предлагает применить новую версию после сохранения данных; автоматического принудительного перезапуска нет.

## Обновление с прежнего маршрутного интерфейса

Старый Service Worker кеширует `/frontend/` и `index.html`, игнорируя параметры URL. При переходе со старой версии открыть `/frontend/update.html` и нажать «Сохранить данные и обновить приложение». Этот дополнительный адрес содержит современную оболочку и не удаляет IndexedDB. Если обновление отложено из-за другой вкладки, сохранить её данные и закрыть её перед повтором.
