# Короткий словарь

| Термин | Что означает сейчас |
|---|---|
| Проект проверки / Audit Project | Конкретная задача сообщества: откуда, куда, для кого и что хотим узнать |
| Часть пути / Route Part | Заранее названная часть: остановка, подход, переход, обход, вход. Не ребро графа |
| Наблюдение / Observation | Запись о конкретном месте и времени с фото и основанием оценки |
| Личный опыт | Участник сам прошёл этот участок; это не автоматически универсальная доступность |
| Наблюдение на месте | Участник видел условия, но не обязательно проверял их на собственном опыте |
| Предположение | Требует осмотра; не может быть принято как подтверждённое |
| Координатор / модератор | Разбирает записи, конфликты и охват; записывает итог. Роль организационная |
| Охват / Coverage | Отдельная ручная отметка обследования части пути: не обследована, частично, целиком |
| Повторная проверка / Recheck | Новое наблюдение с новым фото, связанное с прежней записью |
| Итог / Conclusion | Датированный вывод для конкретных требований и собранных сведений, а не гарантия |
| Демо | Отдельный вымышленный учебный проект с условными иллюстрациями |
| Accessibility Impact | Название из будущей модели влияния Barrier на ребро графа. В текущем приложении не вычисляется |

`CLEAR_PASSAGE` — свободная конкретная точка. `ABSENT` — ранее отмеченная проблема исчезла; требуется связь с прежней записью. Ни один из этих ответов не означает, что весь путь обследован.

Полный прежний словарь, включая Barrier, Mobility Profile и Pedestrian Edge, находится в [архиве](archive/04-domain-glossary.md).
