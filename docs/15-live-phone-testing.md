# Живое тестирование на Android по USB

Локальный сервер Vite передаётся на телефон через adb reverse. В Chrome телефона прототип открывается по адресу http://localhost:5175/#/audits. Этот адрес считается защищённым контекстом браузера; камера, микрофон и crypto.subtle доступны при поддержке и разрешениях браузера.

## Первое подключение Pixel

1. Подключить телефон к Mac кабелем, разблокировать экран.
2. В настройках телефона открыть «О телефоне» и семь раз нажать «Номер сборки».
3. Открыть «Система → Для разработчиков», включить «Отладка по USB».
4. В запросе телефона разрешить отладку с этого Mac.

## Запуск

В корне репозитория:

```sh
URBANACCESS_BASE=/ pnpm dev --host 127.0.0.1 --port 5175 --strictPort
```

В другом терминале, после появления статуса device у телефона:

```sh
adb devices -l
adb reverse tcp:5175 tcp:5175
adb shell am start -a android.intent.action.VIEW -d 'http://localhost:5175/#/audits' -p com.android.chrome
```

При нескольких устройствах к командам adb добавляется -s с идентификатором нужного телефона. Если adb показывает unauthorized, необходимо подтвердить запрос доверия на телефоне. На этом Mac для обнаружения Pixel понадобился драйвер libusb. Если список устройств пуст при включённой отладке, перезапустить ADB:

```sh
adb kill-server
ADB_LIBUSB=1 adb start-server
adb devices -l
```

Изменения исходного кода обновляют интерфейс через Vite. Сервер и USB-подключение должны оставаться активными. После отключения и повторного подключения кабеля может потребоваться повторить adb reverse.

В режиме разработки Service Worker не регистрируется: это исключает старую кешированную оболочку и ошибки регистрации отсутствующего sw.js. Для проверки офлайн-работы и управляемого обновления PWA используется production-сборка на отдельном адресе. Перезапуск страницы во время разработки возможен после изменений, которые Vite не может обновить без перезагрузки.

Данные сохраняются в браузере телефона для этого адреса. Диктовка зависит от реального сервиса распознавания браузера; разрешение микрофона и качество русской речи проверяются непосредственно на телефоне.

## Завершение

Остановить сервер сочетанием Ctrl+C; убрать проброс:

```sh
adb reverse --remove tcp:5175
```
